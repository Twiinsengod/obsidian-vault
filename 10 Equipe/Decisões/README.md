# Decisões

Uma decisão do Fabio só vale quando está nesta pasta, com `status: ativo`, escrita pelo Grok Bot a partir do sim dele. O Claude não cria decisão.

Chat, handoff e rascunho não substituem uma nota daqui.

- [Registro de decisões](<Registro de decisões.md>) — espelho do registro mantido pelo Grok Bot. Só o Grok Bot escreve aqui.
