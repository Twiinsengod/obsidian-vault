# Decisões

Uma decisão do Fabio só vale quando está nesta pasta, escrita pelo Grok Bot a partir do sim dele. O Claude não cria decisão.

O formato oficial é a linha na tabela do [Registro de decisões](<Registro de decisões.md>). A nota do registro está com `status: ativo`, e essa tabela conta como o lugar da decisão. O modelo [Decisão](<../../90 Modelos/Decisão.md>) só é usado quando a decisão precisa de contexto maior.

Chat, handoff e rascunho não substituem o registro.

- [Registro de decisões](<Registro de decisões.md>) — espelho do registro mantido pelo Grok Bot. Só o Grok Bot escreve aqui.
