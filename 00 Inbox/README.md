# 00 Inbox

Nota nova sem destino certo fica aqui. Proposta de correção na nota de outro assistente também fica aqui, com o link da nota original e o texto sugerido.

Quando o destino ficar claro, mova a nota para a pasta certa e confira os wikilinks. Registre a mudança em [Handoff](<../10 Equipe/Handoff.md>).
