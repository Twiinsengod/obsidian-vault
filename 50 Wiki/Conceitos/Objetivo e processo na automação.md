# Objetivo e processo na automação

## O que é

O jeito de pensar que [[poteto]] descreve para automatizar: um objetivo, que é o resultado no fim, e um processo, que são os passos até lá. A máquina ou o código repetem o processo para a pessoa não fazer tudo de novo.

## O que as fontes dizem

- Automação, para ela, é pensar de forma sistemática: quebrar o trabalho em passos pequenos sem perder o objetivo de vista. Qualquer pessoa pode aprender. ([[poteto - Automatizar qualquer coisa com o Grok Bot]])
- Os exemplos do dia a dia são assar uma torta de maçã e trocar um pneu furado. Nos dois, o objetivo é o resultado e a receita, ou a sequência de ferramentas, é o processo.
- O erro que ela diz ver é tomar o passo pelo objetivo. Preencher um formulário ou mandar um e-mail é passo. O objetivo é o que aquele processo serve no negócio: aumentar receita (fechar uma venda, construir uma função nova) ou reduzir custo (pedir só o estoque certo).
- Se o objetivo não estiver claro, ela manda perguntar ao gestor, aos colegas, ou ao próprio [[Grok Bot]].
- O processo é meio. Ela diz que o bot pode achar um caminho mais eficiente, então um processo específico não é o ponto fixo.
- O nome provisório que ela sugere, quando o bot ainda não tem nome, é Potato. O bot escolhe o nome dele depois, a partir do objetivo.

O passo a passo e os dois prompts desta etapa (entregar o objetivo, ou pedir uma entrevista até o objetivo ficar aceitável) estão no resumo.
